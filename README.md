## 🚀 Projects

### 🧠 **Bachelor’s Thesis – Mobile application for predicting valid kidney donors in uncontrolled asystole and development of a web platform based onmachine learning models**
Bachelor’s Thesis graded **10/10 (Outstanding)** and proposed for **Honors**.

Development of an end-to-end clinical decision support system for the evaluation of valid kidney donors in **uncontrolled donation after circulatory death (uDCD)**.

The project is composed of three main components:

- **Android mobile application** developed in Kotlin for healthcare professionals, implementing a clinically defined rule-based model.
- **Web platform** developed with FastAPI, HTML, CSS and JavaScript to compare the predictions of the rule-based model with Machine Learning models for the same clinical input.
- **Automated Machine Learning pipeline** for data preprocessing, validation, exploratory data analysis, synthetic data generation with CTGAN, model training, evaluation and automatic selection of the best model for each clinical scenario.

The ML pipeline evaluates both real data and real + synthetic data configurations for two stages of the donation process: **during CPR** and **hospital transfer**. Model selection is performed using stratified 10-fold cross-validation, multiple random seeds and Grid Search.

The system also integrates **Firebase** for authentication, user management and prediction storage.

**Technologies:** Python · Scikit-learn · CTGAN · FastAPI · Kotlin · Android · Firebase · HTML · CSS · JavaScript · Git
